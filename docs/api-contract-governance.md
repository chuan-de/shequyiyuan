# API 契约变更治理流程

## 适用范围
- 所有已迁移模块（模块清单、状态、负责人、证据链接统一以 `docs/migration-status.md` 为准）的接口字段变更。
- 包含请求字段、响应字段、错误码、字段语义与枚举。

## 变更准入规则（强制）
1. **任何字段变更必须附兼容策略**：
   - 新增字段：说明默认值、是否 nullable、客户端忽略兼容性。
   - 修改字段：说明双字段过渡方案（旧字段保留期、新字段启用期）。
   - 删除字段：必须登记到“废弃字段清单”并给出下线日期。
2. **任何字段变更必须附版本说明**：
   - 至少更新 `docs/api-contract-versioning.md` 的版本记录。
   - 明确版本号、变更类型（兼容/非兼容）、发布时间窗口。
3. **OpenAPI 文档同步更新**：
   - 必须同步修改 `docs/openapi-migrated-modules.yaml`。
   - 若文档未更新，变更不得合并。

## 评审清单（PR Checklist）
- [ ] 是否修改了字段定义（名称/类型/必填/语义）
- [ ] 是否给出兼容策略（含过渡期与回滚方案）
- [ ] 是否更新版本说明
- [ ] 是否更新 OpenAPI 与前端类型单一来源
- [ ] 是否更新废弃字段清单与下线时间表

## 发布节奏
- 常规契约版本按双周节奏发布。
- 紧急补丁允许插队，但必须在 24 小时内补齐版本记录与兼容说明。


## 与迁移状态文件联动（强制）
- 涉及模块迁移状态变化（Not Started/Partial/Done/Diverged）的契约 PR，必须同步更新 `docs/migration-status.md`。
- 当契约变更导致 legacy 行为偏差时，模块状态应评估是否调整为 `Diverged`，并在状态文件补齐证据链接。
- `route-migration-final-report` 与 `p1-iteration-module-plan` 的完成度引用必须指向状态文件，禁止在各文档维护独立完成度口径。
