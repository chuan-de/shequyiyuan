# API 契约版本说明

## 版本策略
- 采用语义化契约版本：`MAJOR.MINOR.PATCH`。
- `MAJOR`：非兼容变更（删除字段、修改字段类型）。
- `MINOR`：兼容新增（新增可选字段、新增错误码但不改变原语义）。
- `PATCH`：文档修订或无行为变化的纠错。

## 版本记录
| 版本 | 日期 (UTC) | 变更类型 | 说明 |
| --- | --- | --- | --- |
| 1.0.0 | 2026-05-05 | 基线 | 已迁移模块契约基线，输出 OpenAPI 文档并建立治理流程。 |

## 非兼容变更发布要求
1. 至少提前 2 个迭代通知调用方。
2. 必须提供并行兼容窗口（建议 >= 60 天）。
3. 发布说明中必须包含迁移示例与回滚策略。
