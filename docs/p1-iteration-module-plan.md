# P1 模块迭代计划与闭环验收记录（第 1 轮）

## 1) 本迭代 P1 模块优先级选择

结合业务价值、跨模块依赖和上线风险，当前迭代进入 3 个 P1 模块：

1. **药品（medication / legacy: yaopin）**：高频主流程，优先级 P1-1。
2. **家庭医生（familyDoctor / legacy: jiatingyisheng）**：居民签约核心链路，优先级 P1-2。
3. **配置（config / legacy: peizhi）**：支撑型模块，影响面广，优先级 P1-3。

> 说明：若迭代容量收缩，保底交付前 2 个模块（药品 + 家庭医生）。

---

## 2) 模块闭环交付清单（统一 DoD）

每个模块必须同时满足以下交付项，才可判定“完成”：

- 列表（List）
- 详情（Detail）
- 新增（Create）
- 编辑（Update）
- 状态变更（Enable/Disable 或发布/停用）
- 权限校验（RBAC + 资源级校验）
- 模块级审计日志（成功/失败均记录）
- 统一异常处理接入（业务异常、参数异常、权限异常）
- legacy 对照验收与差异记录

---

## 3) 分模块交付范围与验收标准

### 3.1 药品模块（P1-1）

**功能闭环范围**
- 列表：支持关键字、状态过滤、分页排序。
- 详情：支持按主键查询 + 不可见状态安全返回。
- 新增：药品编码唯一性校验，基础字段完整性校验。
- 编辑：支持乐观锁/版本控制，防止覆盖更新。
- 状态变更：启用/停用，停用后受限于下游引用规则。
- 权限校验：`medication:read`、`medication:write`、`medication:status`。

**审计日志要求**
- 记录动作：`MEDICATION_LIST/DETAIL/CREATE/UPDATE/STATUS_CHANGE`。
- 记录维度：操作者、对象 ID、关键字段变化摘要、traceId、结果状态。

**异常处理要求**
- 业务异常：重复编码、非法状态流转、依赖占用不可停用。
- 参数异常：字段缺失/格式错误统一返回标准错误体。
- 权限异常：403 且输出最小化错误信息。

**legacy 对照验收（每次模块完成后执行）**
- 对照对象：legacy `yaopin` 菜单与接口行为。
- 验收项：字段一致性、状态语义一致性、错误码差异、权限矩阵差异。
- 产物：差异清单 + 处置结论（修复/接受偏差/待后续）。

---

### 3.2 家庭医生模块（P1-2）

**功能闭环范围**
- 列表：签约关系分页检索（居民、医生、状态、时间范围）。
- 详情：签约档案与服务关系快照。
- 新增：签约创建，校验居民与医生主体有效性。
- 编辑：签约信息更新（服务包、有效期、备注）。
- 状态变更：签约生效/暂停/解约，受状态机约束。
- 权限校验：`familyDoctor:read`、`familyDoctor:write`、`familyDoctor:status`。

**审计日志要求**
- 记录动作：`FD_LIST/DETAIL/CREATE/UPDATE/STATUS_CHANGE`。
- 记录敏感变更：服务包、签约有效期、解约原因。

**异常处理要求**
- 业务异常：重复签约、无效主体、非法状态迁移。
- 参数异常：时间范围、必填字段与枚举值校验。
- 权限异常：组织/辖区越权访问拦截。

**legacy 对照验收（每次模块完成后执行）**
- 对照对象：legacy `jiatingyisheng`。
- 验收项：签约状态映射、历史记录可追溯性、角色权限差异。
- 产物：对照记录 + 差异闭环单。

---

### 3.3 配置模块（P1-3）

**功能闭环范围**
- 列表：按配置分组/键名检索与分页。
- 详情：展示值、生效范围、版本信息。
- 新增：键名唯一性、默认值/类型校验。
- 编辑：配置值变更与版本递增。
- 状态变更：启用/禁用与灰度生效控制。
- 权限校验：`config:read`、`config:write`、`config:status`。

**审计日志要求**
- 记录动作：`CONFIG_LIST/DETAIL/CREATE/UPDATE/STATUS_CHANGE`。
- 强制记录前后值摘要（脱敏后）与影响范围。

**异常处理要求**
- 业务异常：键冲突、类型不匹配、非法生效范围。
- 参数异常：值格式校验失败（布尔/数值/JSON）。
- 权限异常：仅管理员可执行写入与状态变更。

**legacy 对照验收（每次模块完成后执行）**
- 对照对象：legacy `peizhi`。
- 验收项：配置项命名兼容、默认值行为一致性、缓存刷新行为差异。
- 产物：差异记录与回归结论。
